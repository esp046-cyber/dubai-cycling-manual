Dubai Pedal ZIP Builder

This page contains every project file. Tap the button to create a ready-to-upload ZIP on your iPhone. No internet needed.

Ready.
  1. Tap Build ZIP, then Download. Save to Files.
  2. Tap the ZIP in Files to extract it.
  3. In Safari, create a GitHub repository and use Add file, then Upload files.
  4. Select everything from the extracted folder and commit.
